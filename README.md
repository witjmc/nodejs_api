# week4 : 프로토콜별 포트 번호 조회 서비스(Express + fetch) (작성일: 2024.03.04)
## 프로토콜 이름을 입력하면 해당 포트 번호 알려주는 포트 조회 API 서버
### 1단계: 서버 시작(백엔드)
npm i express cors
node index.js
 node index.js 를 실행하면 Express 앱이 만듦
 app.use(cors()) 로 다른 출처(HTML파일)에서 오는 요청을 허용하도록 설정
 라우트(/, /port/:name) 를 등록
 app.listen(3000) 으로 3000 번 포트에서 요청을 계속 기다린다. 이 시점부터 서버는 대기 상태
### 2단계: 사용자가 값을 입력하고 버튼 클릭(프론트엔드)
 사용자가 입력창에 http 를 입력
 api 요청 버튼을 누르면 onclick="getPort()" 에 의해서 getPort() 함수가 실행
 함수 안에서 document.getElementById('name').value 로 입력창의 값(http) 을 가져옴
### 3단계: 서버로 요청 전송
 입력값을 주소에 끼워 넣어 http://localhost:3000/port/http 로 GET 요청을 보냄
 fetch 는 비동기라서 응답을 기다리는 동안 다른 작업을 막지 않고, 응답이 오면, .then() 에 적어둔 함수가 실행
### 4단계 : 서버가 요청을 처리
fetch(`http://localhost:3000/port/${name}`)
 서버는 들어온 주소가 /port/:name 형태와 맞는지 확인
 일치하므로 해당 콜백 함수가 실행되고, 주소의 :name 자리에 있던 값이 req.params 에 담김
 여기서 name:'http' 이다.
 console.log(name) 으로 서버 터미널에 받은 값을 출력
 if/else if 순서대로 비교, ftp 인가? 아닌가? ssh인가? 아닌가? 조건에 맞으면 res.json({port:'80(tcp)'}) 를 실행하고 나머지 조건은 검사하지 않음
 어떤 조건에 맞지 않으면 마지막 else 에서 { port :' 알수 없음'} 을 응답함
### 5단계 : 응답을 받아 화면에 표시
.then((response) => response.json())
.then((data) => { ... })
 첫 번째 .then : 서버가 보낸 응답 (json 문자열) 을 자바스크립트 객체로 변환
 두 번째 .then : 변환된 객체 {port:'80(tcp)' } 가 data 로 들어옴
 console.log(data) 로 F12 콘솔에 출력
